# Prologue - Welcome to Pumpki

**Order of Events**
1. Logos
2. Exposition Cutscene
3. Tutorial


Logos.

The game starts in Pumpkin Patch. We see melons invade the pumpkin patch.


**Cutscene:** Life is good and peaceful in Pumpki Town, then humans plant watermelons in the pumpkin patch. The watermelons overrun Pumpki Town and reduce it to ruins.

The main character then starts in a desolate Pumpki Town with only a few citizens.
